# Jumpgate Brand Sources

These sources generate the user-facing artwork shipped by the Android fork. The
mark, backdrop, Oxanium font, and font license are mirrored byte-for-byte from the
audited `ruizkinio/Jumpgate` coordination repository.

Generated PNG and JPEG assets are committed because Kodi's platform packaging
consumes raster artwork. Regenerate them with `render-brand-assets.ps1` on Windows
and review every resulting image before release.

Kodi remains credited in project documentation and by the splash-screen phrase
`Powered by Kodi`; no Kodi wordmark or logo is used by the distributed application.
